# Problem Solving Repository

This repository contains my personal solutions to programming challenges, mainly from Codeforces and similar competitive programming platforms.  
The goal of this project is to practice algorithmic thinking, improve my coding skills, and track my progress across different problem types and difficulty levels.

## 📁 Structure
Each difficulty level or problem category is organized into its own branch.  
This keeps the main branch clean and focused on documentation, while solutions live in their respective working branches.

## 🧠 Purpose
- Build a solid foundation in algorithms and data structures  
- Strengthen problem-solving skills through consistent practice  
- Maintain a clear history of improvements and coding patterns  
- Share my journey as I progress through more complex challenges  

## 🚀 Future Improvements
- Add multiple programming languages (C++, JavaScript, Python…)
- Include explanations for selected problems
- Add automated scripts to organize and validate solutions

Feel free to explore the branches to see the solutions and follow the evolution of my learning process.
